### 8.1 记忆系统方案（`docs/记忆系统设计方案.md`）

用户愿景（已拍板）：记忆系统 + AI 硬件 + 平台打通 → 学生 24h 数据全方位分析进化。方案落盘为**四层学生数字档案**（进化引擎的读写层）：

| 层      | 内容                                                           | 落地批次                                                            |
| ------- | -------------------------------------------------------------- | ------------------------------------------------------------------- |
| L1 状态 | 现在该知道什么（事件溯源可重算，每次写带 evidence+confidence） | M3                                                                  |
| L2 事件 | 发生过什么（`memory_events` 统一事件流）                       | M2                                                                  |
| L3 会话 | 我们说过什么（AI 导师对话记忆）                                | **M1 先行**（灵犀 `AiConversation`，照抄 agent_conversations 范式） |
| L4 语义 | 值得记住的归纳（预留 strength/importance/never-forget）        | M3                                                                  |

事件流协议中立：OAR 轨迹格式 + `source=real|synthetic` 同表同管线 + modality 开放枚举 + 双时间戳 + 幂等同步。

### 8.2 从将来技术看今天（`docs/从将来技术看今天项目.md`，12 路调研）

用户要求"所有维度再调查一次，从将来技术看今天"。两轮 workflow（18 agents）综合结论：

- **终局判断**：每个学生一份「持久学习者模型」——跨设备 24h 事件流喂养的数字学籍，所有 AI 导师读写；批改/眼镜/机器人/学习机都只是同一档案的传感器。窗口期 2026-2028 埋种子。
- **三颗种子（全部不依赖真实数据、合成直接点火）**：① `memory_events` 协议中立（唯一不建就永远补不上的种子）② 合成学生仿真场（教育界空白护城河，天工 Omni 类比：仿真进化+真实验收锚）③ 四层记忆按持久学习者模型标准建。
