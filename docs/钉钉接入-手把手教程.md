# 钉钉免登接入 · 手把手教程（零基础版）

> 目标：让老师点钉钉工作台的「叙阅」图标，**不用输密码直接进去**
> 本教程用**你自己的手机 + 你自己的钉钉**，不用找学校
> 全程约 1.5 小时，分 7 步，每步都截图般详细

---

# 准备清单

开始前确认你有：

- [ ] 一部手机（装了钉钉）
- [ ] 一台能上网的电脑
- [ ] 会用浏览器填表单
- [ ] 叙阅的后端代码能打开（`D:\job2\批改君\grade-buddy-scan-back_end`）

**全程不需要写代码**——代码我会给你，复制粘贴就行。

# 第 1 步：手机上建一个「组织」（约 10 分钟）

> 「组织」就是钉钉里的一个公司/团队。你要先有组织，才能建应用。
> 用自己的手机号建，**免费**，随便起名。

## 1.1 下载钉钉

手机应用商店搜「**钉钉**」→ 下载 → 打开。

## 1.2 注册登录

用你的**手机号**注册登录（收到验证码填进去）。

## 1.3 创建组织

登录后，如果没进过任何组织，钉钉会引导你创建。如果直接进了一个页面，就手动找：

```
钉钉底部「我的」 → 找到「设置」或头像 → 「企业/团队」 → 「创建团队」
```

**填什么**：

| 项 | 填什么 | 举例 |
|---|---|---|
| 团队名称 | 随便起 | `叙阅测试` |
| 行业 | 随便选 | `教育培训` |
| 人数 | 随便选 | `1-10人` |
| 你的名字 | 你的名字 | 张三 |
| 职位 | 随便 | 管理员 |

点「创建」。

## 1.4 ✅ 检查这一步成功了没

创建完，钉钉底部会出现「**工作台**」这个标签。

**点进去能看到工作台，就成功了。**

> 💡 **重要**：现在你是这个组织的「**主管理员**」，后面申请权限时**你自己就能批**，秒过。

> 「应用」就是工作台上那个图标。老师点它，就进你的系统。

## 2.1 打开开发者后台

登录后看**右上角**，应该显示「**叙阅测试**」。
如果不是，点右上角切换过去。

> ⚠️ 这步很关键——切错组织，后面建的的东西就不在你自己的组织里。

## 2.3 创建应用

```
顶部「应用开发」 → 「创建应用」
```

**填什么**：

| 项 | 填什么 |
|---|---|
| 应用类型 | 选「**网页应用**」（有的版本叫「H5 微应用」） |
| 应用名称 | `叙阅` |
| 应用图标 | 随便传一张 PNG 图片（256×256 最好，不上传也行） |
| 应用描述 | `作业批改系统` |

点「**确定/创建**」。

## 2.4 ✅ 检查这一步成功了没

创建完会跳进应用的详情页，页面上能看到一行 **AppKey** 和 **AppSecret**。

看到这两个，就成功了。

## 5.2 新建一个文件

在 `app\` 目录下新建文件 `dingtalk.py`，把下面**全部内容**复制进去：

```python
# -*- coding: utf-8 -*-
"""钉钉免登：authCode 换 userid → 匹配叙阅账号 → 发自己的 JWT"""
import os
import time
import threading
import requests
from fastapi import APIRouter, Depends, HTTPException
from pydantic import BaseModel
from sqlalchemy.orm import Session

from app.database import get_db
from app.models.user import User
from app.utils.security import create_access_token
from app.schemas.common import ApiResponse

router = APIRouter(prefix="/auth", tags=["dingtalk"])

_DING_BASE = "https://oapi.dingtalk.com"
_lock = threading.Lock()
_cache = {"token": None, "expire_at": 0.0}


def _ding_token() -> str:
    """拿钉钉的通行证（access_token），自动缓存、提前 5 分钟刷新。"""
    app_key = os.environ.get("DINGTALK_APP_KEY", "").strip()
    app_secret = os.environ.get("DINGTALK_APP_SECRET", "").strip()
    if not app_key or not app_secret:
        raise RuntimeError("未配置 DINGTALK_APP_KEY / DINGTALK_APP_SECRET")

    with _lock:
        now = time.time()
        if _cache["token"] and now < _cache["expire_at"] - 300:
            return _cache["token"]
        r = requests.get(
            f"{_DING_BASE}/gettoken",
            params={"appkey": app_key, "appsecret": app_secret},
            timeout=10,
        ).json()
        if r.get("errcode") != 0:
            raise RuntimeError(f"拿钉钉通行证失败：{r.get('errcode')} {r.get('errmsg')}")
        _cache["token"] = r["access_token"]
        _cache["expire_at"] = now + int(r.get("expires_in") or 7200)
        return _cache["token"]


class DingLoginBody(BaseModel):
    code: str


@router.post("/dingtalk-login", response_model=ApiResponse[dict])
def dingtalk_login(body: DingLoginBody, db: Session = Depends(get_db)):
    """前端在钉钉里拿到 code → 这里换身份 → 发叙阅自己的令牌。"""
    code = (body.code or "").strip()
    if not code:
        raise HTTPException(status_code=400, detail="缺少免登授权码")

    # 1) 用 code 换「这个人是谁」
    try:
        r = requests.post(
            f"{_DING_BASE}/topapi/v2/user/getuserinfo",
            params={"access_token": _ding_token()},
            json={"code": code},
            timeout=10,
        ).json()
    except Exception as e:
        raise HTTPException(status_code=502, detail=f"调用钉钉失败：{e}")

    if r.get("errcode") != 0:
        # 40078 = code 过期或已用过
        raise HTTPException(
            status_code=401,
            detail=f"钉钉免登失败 {r.get('errcode')}: {r.get('errmsg')}",
        )
    info = r.get("result") or {}
    ding_name = info.get("name") or ""
    ding_mobile = info.get("mobile") or ""

    # 2) 在叙阅里找这个人：先用手机号，再用姓名兜底
    user = None
    if ding_mobile:
        user = db.query(User).filter(User.phone == ding_mobile).first()
    if not user and ding_name:
        hits = db.query(User).filter(User.display_name == ding_name).all()
        if len(hits) == 1:      # 只有唯一匹配才认，避免重名串号
            user = hits[0]

    if not user:
        raise HTTPException(
            status_code=403,
            detail=f"钉钉账号「{ding_name}」未匹配到叙阅账号，请联系管理员绑定",
        )

    # 3) 发叙阅自己的令牌（后面所有请求都只认它，不再用钉钉信息）
    token = create_access_token(user.id)
    return ApiResponse(data={
        "access_token": token,
        "user": {"id": user.id, "email": user.email, "display_name": user.display_name},
    })
```

# 第 6 步：前端加一个「入口页」（约 20 分钟）

> 这个页面专门给钉钉用：打开 → 自动登录 → 跳进主页。

## 6.1 安装钉钉的 JS 工具包

在 `D:\job2\批改君\grade-buddy-scan-main\` 目录下，打开命令行执行：

```

```

## 6.2 新建入口页

在 `src\pages\` 下新建文件 `DingTalkEntry.tsx`，内容：

```tsx
import { useEffect, useState } from "react";
import * as dd from "dingtalk-jsapi";
import { API_PREFIX } from "@/config/api";

const TOKEN_KEY = "grade_buddy_access_token";

export default function DingTalkEntry() {
  const [err, setErr] = useState("");

  useEffect(() => {
    // 不在钉钉里打开：给个明确提示，别白屏
    if (!dd.env.platform || dd.env.platform === "notInDingTalk") {
      setErr("请在钉钉工作台中打开「叙阅」");
      return;
    }

    // 工作台打开时，网址里会自动带上 corpId
    const corpId =
      new URLSearchParams(location.search).get("corpId") ||
      (import.meta.env.VITE_DINGTALK_CORP_ID as string) ||
      "";

    dd.ready(async () => {
      try {
        // 1) 跟钉钉要「进门条」
        const res: any = await dd.runtime.permission.requestAuthCode({ corpId });
        const code = res?.code;

        // 2) 拿进门条找叙阅后端换令牌
        const r = await fetch(`${API_PREFIX}/auth/dingtalk-login`, {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ code }),
        });
        const data = await r.json();
        if (!r.ok) throw new Error(data?.detail || "免登失败");

        // 3) 存下令牌，进主页
        localStorage.setItem(TOKEN_KEY, data.data.access_token);
        location.replace("/");
      } catch (e: any) {
        setErr(e?.message || String(e));
      }
    });
  }, []);

  if (err) {
    return (
      <div style={{ padding: 40, fontSize: 16, textAlign: "center" }}>
        <p>❌ {err}</p>
        <p style={{ color: "#888", fontSize: 14 }}>（把这句话截图发给技术，能快速定位）</p>
      </div>
    );
  }
  return <div style={{ padding: 40, textAlign: "center" }}>正在登录…</div>;
}
```

> 💡 **为什么要写错误提示**：钉钉容器里出错默认是**一片白屏**，什么都看不到，排查起来极其痛苦。有了这个提示，出了问题你能直接把文字发给技术。

## 6.3 注册路由

打开 `src\App.tsx`，找到其他 `<Route>` 的地方，加一行：

```tsx
<Route path="/dingtalk/entry" element={<DingTalkEntry />} />
```

并在文件顶部加：

```tsx

```

> ⚠️ 这个路由**要放在登录校验的外面**（不然没登录就被拦去登录页了）。如果你不确定放哪，就放在最前面。

# 出错了怎么办（对照表）

| 你看到什么 | 什么原因 | 怎么办 |
|---|---|---|
| 页面**一片白** | 没在钉钉里打开，或 JS 没加载 | 确认是用手机钉钉点的图标 |
| 「请在钉钉工作台中打开」 | 用普通浏览器打开了 | 这是**正常的**，去钉钉里点 |
| 「钉钉账号「张三」未匹配到叙阅账号」 | 手机号对不上 | 去叙阅后台改手机号（第 7.1 步） |
| 「钉钉免登失败 40078」 | 进门条过期了（5 分钟） | 退出来**重新点一次图标** |
| 「钉钉免登失败 40014」 | AppKey/AppSecret 填错了 | 核对第 5.1 步的 .env |
| 工作台**找不到图标** | 没发布 / 可见范围没包含你 | 回到 4.4 和 4.5 再来一遍 |
| 改了配置**没反应** | **忘了发布版本** | 回后台 → 版本管理与发布 → 再发一次 |
| 手机能进、电脑白屏 | 两端首页地址不一致 | 4.1 里两端都填同样的地址 |

# 以后换成学校的怎么办

代码里所有参数都在 `.env` 里（没写死），所以：

```
1. 学校给一套新参数
2. 改 .env 里那 4 行
3. 改后端工作台可见范围
4. 后台重新发布一版
```

**代码一行都不用改。**
